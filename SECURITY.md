# Security Policy

Please never report possible security issues on public GitHub tickets. Instead please preferredly report responsibly via the "Private vulnerability reporting" feature on GitHub only. Alternatively contact us via mail on our site only

## Important

- Reports should preferredly be made based on the latest master on GitHub and not based on the latest official relase only. Issues already may have been fixed. Note that the master may contain unfinished work and not work properly at all especially in alpha status.
- Check existing tickets to avoid duplicates before submitting a new one (if possible as you may not see private security reports)
- Only report one issue per ticket
- Please be responsive on follow up comments and questions from us. Pure AI reports without responses may be closed/ignored without investigation
- Keep your report short and to the point. If you use AI assistance, disclose this and review if posting the often lengthly report is really necessary especially on smaller issues.
