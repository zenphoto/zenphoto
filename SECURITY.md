# Security Policy

Please never report possible security issues on public GitHub tickets. Instead please preferredly report responsibly via the "Private vulnerability reporting" feature on GitHub only. Alternatively contact us via mail on our site only

## Important

- Reports should preferredly be made based on the master on GitHub and not based on the latest official relase only. Issues already may have been fixed. Note that the master may contain unfinished work and not work properly at all especially in alpha status.
- Check existing tickets to avoid duplicates before submitting a new one (if possible)
- Only report one issue per ticket
