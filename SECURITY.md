# Security Policy

Please never report possible security issues on public GitHub tickets as those are public. Instead please preferredly report responsibly via the "Private vulnerability reporting" feature on GitHub only. Alternatively contact us via mail on our site only**

## Important

- Reports should preferredly be made based on the current support/development build (master) on GitHub and not based on the latest official relase only. Issues already may have been fixed.
- Check existing tickets to avoid duplicates before submitting a new one.
- Only report one issue per ticket
